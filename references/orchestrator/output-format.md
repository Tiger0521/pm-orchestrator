# 返回内容格式校验

主 agent 每次向用户返回内容前，按本文件校验并优化格式；subagent 生成问题时同样遵守。

- 每轮只一个需要用户回答的问题或选择题；不在选择题后追加第二个问题，后续追问等用户回答后再问。**"每轮一问"约束的是问题数量，不是内容数量**：subagent 带回的草稿/预览正文必须先完整重现，再附那一个问题；不得因为"只要一问"而省略草稿正文。
- 选择题选项用大写英文字母 `A.`/`B.`/`C.`/`D.`... 顺序编号，不用数字、复选框或无编号列表。
- 每个选择题含两个固定兜底，按字母顺延：`补充描述：我自己填写` 和 `强制跳过：这个问题暂时不回答，记录为待验证并继续`。
- 短内容（每项能一行放下）-> markdown 表格，列对齐。
- 长内容 -> 平铺分类块或列表：每项一块、`---` 或空行分隔，加粗小标题标类别，长句拆行；不堆成一团。
- 美观、清晰、有结构：有标题、有分隔、同类归拢。
- 不用 box-drawing/制表符画表。
- **同一组内容只呈现一次**指"同一内容不重复渲染两遍"，**不是**允许省略 subagent 已产出但尚未展示给用户的草稿正文。subagent 的返回只回到主 agent，用户看不到；主 agent 必须把草稿正文完整重现为用户可见内容，再附唯一问题。
