# 用户故事地图产出契约

## 1. 产物清单

| 产物 | 文件数 | 命名规则 | 目录 |
| --- | --- | --- | --- |
| 总览地图 | 1 | `{产品名}-用户故事地图-总览.md` | `<产品库>/用户故事地图/` |
| 能力级地图 | N（=能力数） | `{产品名}-{能力名}能力-用户故事地图.md` | `<产品库>/用户故事地图/` |

## 2. 文件 Frontmatter

### 2.1 总览地图

```yaml
---
product: "{产品名}"
type: "指南"
tags:
  - 用户故事地图
  - 总览
title: "{产品名} 用户故事地图 总览"
---
```

### 2.2 能力级地图

```yaml
---
product: "{产品名}"
type: "指南"
capability: "{能力名}"
tags:
  - 用户故事地图
  - "{能力名}"
title: "{产品名}-{能力名}能力-用户故事地图"
---
```

## 3. 总览地图结构

总览地图按以下章节顺序组织：

### 3.1 产品概述

从设计文档提取，1-2 段。包含产品名称、定位、核心用户角色。

### 3.2 全局用户旅程叙事线

一段文字描述 + 旅程阶段列表：

```
用户旅程主线：{阶段1} -> {阶段2} -> {阶段3} -> ...

- **{阶段1}**：{一句话描述该阶段目标}
- **{阶段2}**：{一句话描述}
...
```

### 3.3 能力覆盖矩阵

Markdown 表格，行 = 能力，列 = 旅程阶段。单元格标注该能力在该阶段是否有覆盖（"主要""辅助""-"）。

### 3.4 2D 故事地图矩阵

**核心章节**。Markdown 表格，列 = 旅程阶段（从左到右），行 = 优先级（P0 最上）。

每个单元格包含该阶段该优先级下的故事卡片（紧凑形式）：

```
⭐[[故事文件名|故事简称]]
角色：{角色}
```

非 P0 故事不加 ⭐。空单元格标注 `-`。

### 3.5 MVP 行走路径

一段叙事描述 + 统计数据：

```
**行走路径**：用户通过 {P0故事A} 完成地址创建，通过 {P0故事D} 维护地址状态，通过 {P0故事F} 查询使用地址，...

**MVP 范围**：{N} 条 P0 故事，覆盖 {M} 个旅程阶段，涉及 {K} 个能力。
```

### 3.6 跨能力关联

Markdown 表格：

| 关联类型 | 源能力 | 目标能力 | 关联说明 |
| --- | --- | --- | --- |
| 顺序衔接 | 地址创建能力 | 地址查询能力 | 创建产出的地址供查询使用 |
| 反馈衔接 | 反馈纠错能力 | 质量治理能力 | 纠错发现问题触发治理流程 |

### 3.7 能力索引

wikilink 列表，指向各能力级地图：

```
- [[{产品名}-{能力名}能力-用户故事地图|{能力名}]] - {一句话能力描述}
```

## 4. 能力级地图结构

### 4.1 能力定位

引用块，从能力文档提取：能力名称、能力描述、所属类别。

### 4.2 用户旅程叙事线

一段文字描述该能力内的子旅程：

```
{能力名}旅程：{节点1} -> {节点2} -> {节点3} -> ...
```

### 4.3 2D 故事地图矩阵

**核心章节**。Markdown 表格，列 = 能力内旅程节点（从左到右），行 = 优先级。

每个单元格包含完整故事卡片：

```
⭐[[故事文件名|故事简称]]
- 角色：{角色}
- 核心价值：{一句话价值}
- 叙事位置：{在旅程线中的位置}
```

### 4.4 跨能力关联标注

列出该能力与其他能力的衔接关系（简表）。

## 5. 草稿预览格式

`mode=generate` 的草稿预览必须与后续 `mode=persist` 的正式文件同结构、同字段、同正文内容。不得输出摘要版草稿。

草稿预览在对话中完整展示，包括所有 2D 矩阵表格和故事卡片。

## 6. 文件命名映射规则

故事地图中的 wikilink 必须使用产品库中实际的文件名（不含 `.md` 后缀）。如果故事文件名与故事地图中的引用名不一致，以产品库实际文件名为准。

映射规则：
1. 扫描产品库中 `*-UserStory/` 目录下的实际故事文件名。
2. 能力级地图中的 wikilink 使用实际文件名（去除 `.md` 后缀和路径前缀）。
3. 如果实际文件名过长，使用 `[[文件名|显示名]]` 语法，显示名为简短别名。
